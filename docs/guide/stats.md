# 统计分析

【统计分析】模块从多个维度展示停车收费数据的整体情况，帮助你快速了解收入构成与变化趋势。

## 金额汇总卡片

页面顶部展示四个核心指标：

| 指标 | 说明 |
|------|------|
| 总记录数 | 数据库中所有停车记录的总条数 |
| 应收总额 | 所有记录应收金额的合计 |
| 实收总额 | 所有记录实收金额的合计 |
| 未收金额 | 应收总额减去实收总额的差额 |

点击右上角 **“刷新统计”** 按钮可重新计算最新数据。

## 分布统计

系统按以下维度展示分布情况，每个维度包含数量、应收金额、实收金额：

- **车辆类型分布**：如临时车、月租车等；
- **放行方式分布**：如自动放行、免费放行等；
- **缴费方式分布**：如现金、微信支付、支付宝等；
- **收费车型分布**：如小型车、新能源车等。

每个表格默认显示前 10 条数据。

## 趋势统计

### 月度收费趋势

按自然月汇总记录数、应收金额、实收金额，便于观察长期收入变化。

### 每日收费趋势（最近 30 天）

按天汇总最近 30 天的记录数、应收金额、实收金额，便于观察短期收入波动。

> 提示：导入新 ZIP 文件或清空数据库后，建议刷新统计以查看最新结果。
