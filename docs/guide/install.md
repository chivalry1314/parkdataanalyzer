# 安装与启动

## 下载安装包

1. 打开 GitHub 仓库的 [Releases](https://github.com/chivalry1314/parkdataanalyzer/releases) 页面；
2. 找到最新版本，根据你的操作系统下载对应的安装包：

| 操作系统 | 安装包类型 | 说明 |
|----------|------------|------|
| Windows | `.exe`（NSIS 安装包） | 双击运行安装向导 |
| Windows | `.msi` | 微软安装包，适合企业静默部署 |

3. 下载完成后，按常规方式安装即可。

## 首次启动（初始化向导）

安装完成后，从开始菜单或桌面快捷方式启动 **PARKINGSYSLOG**。

首次启动时软件还没有数据库，会显示**初始化向导**，引导你选择数据库文件的存放位置。所有停车收费记录都会保存在这一个 SQLite 文件中。向导提供三个选项：

- **选择存放位置（新建数据库）**：在弹出的对话框中指定一个目录和文件名（如 `parkingsyslog.db`），软件会在该位置创建新的空数据库；
- **选择已有的数据库文件**：如果你之前备份过或从其他电脑迁移了 `.db` 文件，可以直接选择它来继续使用其中的数据；
- **使用默认位置**：在应用数据目录下创建数据库，适合不确定选哪里时使用。

选择建议：

- 建议选择便于备份的目录，例如 D 盘或文档目录；
- 请勿选择系统目录（如 Program Files），可能没有写入权限；
- 之后也可以在【设置】页面修改存放位置（见 [设置](./settings.md)）。

确认后软件会自动完成初始化并重启，随后即可正常使用。

## 界面介绍

启动后进入主界面：

### 主要区域

1. **左侧导航栏**：快速切换各功能模块；
2. **顶部标题栏**：显示当前页面名称，右侧提供与该页面相关的快捷操作（如选择 ZIP 文件、清空数据库）；
3. **内容区**：展示数据列表、统计卡片、表单等。

### 菜单说明

| 菜单 | 简称 | 说明 |
|------|------|------|
| 记录列表 | 列 | 查看与筛选所有停车收费记录 |
| 车辆收费 | 车 | 按车牌查询月度收费与明细 |
| 统计分析 | 统 | 查看汇总金额与分布趋势 |
| 设置 | 设 | 查看与修改数据库存储路径 |

## 更新版本

当有新版本发布时：

1. 下载对应平台的最新安装包；
2. 直接安装即可覆盖旧版本；
3. 数据库文件会自动保留，无需重新录入数据。

> 注意：如果修改过数据库路径，升级前请确认路径设置，避免误用空数据库。
