# 车辆收费

【车辆收费】模块用于按车牌查询某辆车的月度收费汇总，并下钻查看具体月份的明细记录，支持导出 Excel。

## 查询车牌

1. 在 **车牌号** 输入框中输入完整车牌，如 `京A12345`；
2. 按回车键或点击 **“搜索”** 按钮；
3. 系统会按月份汇总该车辆的收费记录。

查询结果包含以下信息：

| 字段 | 说明 |
|------|------|
| 月份 | 统计月份，如 `2024-01` |
| 记录数 | 该月停车记录条数 |
| 应收金额 | 该月应收金额合计 |
| 实收金额 | 该月实收金额合计 |
| 未收金额 | 该月未收金额合计 |

## 按时间筛选

点击 **“更多筛选”** 可展开时间范围条件：

- 进场时间起止
- 出场时间起止

设置后点击 **“搜索”**，系统只会在指定时间范围内统计。

## 查看明细

1. 在月度汇总列表中，点击某个月份右侧的 **“详情”** 按钮；
2. 下方 **收费明细** 区域会显示该月份的所有停车记录；
3. 明细列表支持分页查看。

明细记录包含：车牌号、进场时间、出场时间、停车时长、应收金额、实收金额、放行方式、来源文件。

## 导出 Excel

1. 输入车牌并完成搜索，确保有月度汇总数据；
2. 点击 **“导出 Excel”** 按钮；
3. 在弹出的保存对话框中选择导出位置；
4. 导出成功后右下角会弹出提示。

导出的文件名默认为：

```
车辆收费统计_<车牌>_<日期>.xlsx
```

> 注意：如果没有搜索到任何记录，导出按钮会处于禁用状态。
