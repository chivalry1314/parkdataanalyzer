# 设置

【设置】页面用于查看和修改数据库存储位置，方便你进行数据备份或迁移。

## 查看当前数据库路径

页面会显示当前 SQLite 数据库文件的完整路径。你可以直接复制该文件进行手动备份。

## 修改数据库路径

1. 勾选或不勾选 **“迁移现有数据到新路径”**：
   - 勾选：将当前数据库中的数据复制到新位置；
   - 不勾选：在新位置创建一个空数据库。
2. 点击 **“修改数据库路径”** 按钮；
3. 在弹出的保存对话框中选择新的数据库文件位置；
4. 确认后软件会自动重启并应用新路径。

## 注意事项

- 请勿将数据库文件存放在系统目录（如 `C:\Program Files`），否则可能因权限不足导致写入失败；
- 建议将数据库文件存放在 D 盘、文档目录或其他便于备份的位置；
- 定期复制 `.db` 文件到外部存储或网盘，可防止数据丢失。
