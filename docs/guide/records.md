# 记录列表

【记录列表】是 PARKINGSYSLOG 的核心页面，用于导入 ZIP 压缩包、查看解析后的停车收费记录，并按多种条件进行筛选与分页。

## 导入 ZIP 文件

1. 点击页面右上角 **“选择 ZIP 文件”** 按钮；
2. 在弹出的文件选择器中，找到包含 Excel 进出场记录表的 `.zip` 压缩包；
3. 软件会自动解压并解析其中的 `.xlsx` 文件，进度条会显示当前处理状态；
4. 解析完成后会弹出提示，显示成功导入的记录数量。

### 数据覆盖规则

- 每次导入新 ZIP 时，新记录会**覆盖**数据库中的已有记录；
- 如果需要保留历史数据，请在导入前先备份数据库文件（见 [设置](./settings.md)）。

### 支持的字段

解析后的记录包含以下字段：

- 车牌号、车辆类型、收费车型、车型、车辆品牌、车系
- 车主电话、车主姓名
- 进场时间、进场车道、出场时间、出场车道、停车时长
- 应收金额、实收金额、未收金额
- 领券类型、领券优惠、充电优惠类型、充电优惠金额
- 缴费方式、放行方式、操作者、备注、来源文件

## 筛选记录

点击 **“展开筛选”** 按钮后，可以使用以下条件进行组合筛选：

| 筛选条件 | 说明 |
|----------|------|
| 车牌号 | 支持模糊匹配，如输入 `京A` |
| 车主姓名 | 支持模糊匹配 |
| 车辆类型 | 如：临时车、月租车 |
| 收费车型 | 如：小型车、新能源车 |
| 放行方式 | 如：自动放行、免费放行 |
| 缴费方式 | 如：现金、微信支付 |
| 进场时间 | 起止时间范围 |
| 出场时间 | 起止时间范围 |

设置好条件后点击 **“搜索”**，列表会立即刷新。点击 **“重置”** 可清空所有筛选条件。

## 分页查看

- 每页默认显示 20 条，可通过右上角下拉框切换为 50 条或 100 条；
- 使用底部的 **首页 / 上一页 / 下一页 / 末页** 按钮切换页面；
- 页面底部会显示当前页码与总记录数。

## 清空数据库

点击右上角 **“清空数据库”** 按钮，会弹出确认对话框。确认后，数据库中所有停车收费记录将被删除，此操作不可恢复。

> 警告：清空数据库前请确保已经备份重要数据。
