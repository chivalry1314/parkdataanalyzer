# 文档概述

欢迎使用 **PARKINGSYSLOG** 操作文档。

本软件是一款面向停车场/物业场景的桌面应用，用于解析 ZIP 压缩包中的 **Excel 进出场记录表**，并将停车收费记录持久化到本地 SQLite 数据库，方便后续查询、统计与分析。

## 适用对象

本文档面向：

- 初次使用该软件的停车场管理人员；
- 需要了解各功能模块操作步骤的一线员工；
- 负责数据备份、导出与系统维护的管理员。

## 文档结构

| 章节 | 内容 |
|------|------|
| [安装与启动](./install) | 下载、安装、首次启动与界面介绍 |

| [车辆收费](./vehicle) | 按车牌查询月度汇总与明细，导出 Excel |
| [统计分析](./stats) | 查看金额汇总与各类分布趋势 |

## 界面总览

软件主界面采用经典的侧边栏布局：

- **左侧边栏**：导航菜单，包含记录列表、车辆收费、统计分析、设置；
- **顶部标题栏**：显示当前页面名称与快捷操作按钮；
- **右侧内容区**：展示当前页面的功能与数据。

左侧边栏支持收起/展开，收起后只显示每个菜单的简称（列、车、统、设）。
