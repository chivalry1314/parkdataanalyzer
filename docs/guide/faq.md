# 常见问题

## 导入 ZIP 文件时提示“未在压缩包中找到有效的 Excel 记录文件”

可能原因：

- 压缩包内没有 `.xlsx` 文件；
- Excel 文件的表头格式不符合解析规则；
- 压缩包损坏或加密。

解决方案：

- 确认压缩包内包含进出场记录表的 `.xlsx` 文件；
- 检查 Excel 表头是否包含车牌号、进场时间、出场时间等关键字段；
- 尝试重新压缩文件，确保未设置密码。

## 提示“未指定数据库路径”或无法保存记录

可能原因：

- 首次启动时未正确选择数据库位置；
- 当前数据库路径所在目录没有写入权限。

解决方案：

- 在【设置】页面修改数据库路径到用户有写入权限的目录；
- 避免使用系统目录或只读目录。

## 筛选时间后没有结果

- 时间筛选使用的是进场时间或出场时间字段；
- 确保 Excel 中的时间格式正确，且已经被成功解析；
- 检查起止时间是否设置反了（起始时间晚于结束时间）。

## 如何备份数据

PARKINGSYSLOG 使用单个 SQLite 数据库文件存储所有数据：

1. 打开【设置】页面，复制当前数据库路径；
2. 在文件资源管理器中找到该 `.db` 文件；
3. 将其复制到安全位置（如外部硬盘、网盘）即可。

## 如何迁移数据到另一台电脑

1. 在旧电脑上备份数据库文件；
2. 将 `.db` 文件复制到新电脑；
3. 在新电脑上首次启动时选择 **“选择已有的数据库文件”**，定位到复制的文件即可。

## 启动应用后界面空白或报错

- 检查数据库文件是否被移动或删除；
- 尝试在【设置】中重新指定有效的数据库路径；
- 如果数据库损坏，可以尝试用最近的备份文件替换。
